# deepseek-ai/deepseek-harness

> DeepSeek Harness（dsh）是由 [DeepSeek AI](https://deepseek.com/) 开发的开源 agent harness（智能体框架）。

它采用一切皆插件的架构，并由 [Cordis](https://github.com/cordiverse/cordis) 驱动，其设计参见论文 [A Programming Paradigm for Spatiotemporal Composability](https://github.com/cordiverse/paper)。
